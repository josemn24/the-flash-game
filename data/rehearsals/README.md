# Catálogo de ensayos

Contenido propio para las pruebas locales previas al intento competitivo. No depende de mocks,
fixtures oficiales ni sesiones persistidas.

- `catalog.v1.json`: preguntas versionadas y ensayos con referencias concretas.
- `manifest.v1.json`: identidades y huellas de los artefactos publicados.
- `profiles.v1.json`: perfiles mecánicos sin enunciados ni soluciones.

El procedimiento de autoría, revisión, asociación y conservación de versiones está en
[Pruebas antes del intento competitivo](../../docs/current/rehearsals.md).
