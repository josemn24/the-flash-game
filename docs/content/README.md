# Contenido

Esta sección reúne la documentación editorial y las reglas de autoría de los desafíos y formatos.

- [`formatos-de-juego.md`](formatos-de-juego.md): catálogo de mecánicas, estado de implementación y
  evolución.
- [`challenges/`](challenges/): especificaciones editoriales de desafíos concretos.
- [`guidelines/`](guidelines/): etiquetado y referencias de contenido, incluido Mini-Wordle.

Los formatos nativos del código se registran en la biblioteca y en el registry de scoring. Los
documentos de esta sección pueden describir formatos futuros, pero deben indicar su estado.
